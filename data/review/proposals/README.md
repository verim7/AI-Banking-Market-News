# Proposed grades (retired)

For one day, 28 September 2026, the Routine's grades waited here for the editor
instead of being published. The editor then chose to have grading published
automatically, and to review the weekly email instead. Every grade in these
files was published by `data/review/decisions/2026-09-28-24.jsonl`.

The files stay as the record of what was proposed. Nothing reads them any more
except the tests, which still hold them to the rubric. New grades go to
`data/review/decisions/` (see `data/review/RUBRIC.md`).
