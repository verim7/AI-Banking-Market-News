# Articles to put into the app by URL.
#
# This is NOT a feed list. packages/ingest/sources.yaml holds the feeds — taps
# pointed at publishers, delivering whatever those publishers decide to publish.
# This file holds individual articles somebody found and wants in the corpus.
#
# It exists because Sygnum Bank was missing from the Agentic Swiss Banks page
# for a week. The first live AI-agent driven transactions by a regulated Swiss
# bank were announced on Sygnum's own newsroom, which is not one of the feeds,
# so nothing in the pipeline ever saw it. A hand search found it in minutes and
# there was no way to put it in.
#
# Format:  <url>  [| publisher_kind]
#
# publisher_kind is one of consultancy, regulator, bank, media. It defaults to
# media, and it is worth setting for a bank's own newsroom: `bank` weighs 1.1
# against media's 1.0, and a press release read as anonymous media news is
# scored as though nobody in particular said it.
#
# Run:  npm run seed-urls              (dry run — reads, classifies, writes nothing)
#       npm run seed-urls -- --apply   (writes to the database)
# or the "Seed articles by URL" workflow, which defaults to a dry run.
#
# Re-running is free: an article already stored updates in place.
